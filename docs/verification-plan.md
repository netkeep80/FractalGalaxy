## Конечная численная фикстура E0

Однородный куб `[-1,1]^3` с `ρ=1`: объём/масса 8, центр масс (0,0,0), диагональ тензора инерции (16/3,16/3,16/3). При разбиении по x=0 на две половины масса каждой 4, центр масс (±0.5,0,0). Каждая половина имеет собственную диагональ I=(8/3,5/3,5/3) относительно своего COM; после переноса осей и сложения получается исходный тензор 16/3. Предлагаемый E0 допуск для аналитических операций на f64 = 1e-12 абсолютной ошибки. Это **не гарантия** производительности/точности произвольных фракталов.

Для случайного генератора тестовые seeds и ожидаемые значения нужно зафиксировать только *после* утверждения функции Derive и численной модели; до этого проверяется порядок-независимое равенство на фиксированном наборе адресов. CPU authoritative oracle раньше GPU-визуализации.

Некоторые сценарии (gravity precision, Fuse chemistry, GPU tolerances) **остаются research**, а не полностью исполнимым E0.
