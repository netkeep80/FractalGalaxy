# Проверочный план v0 — не исполнен

Ни один пункт не является `verified_by` до появления выполняемого свидетеля. Подход: сначала попытка фальсификации, потом реализация.

| ID | Положительный случай | Отрицательный случай / ожидаемое нарушение |
|---|---|---|
| V01 | Дети получают seed при фрактализации из seed родителя и ветви; DFS/BFS и разные workers возвращают те же значения | Seed присваивается заново при физическом отрыве либо зависит от порядка вызовов |
| V02 | Уточнение 3D и 2D даёт согласованные общие границы и одинаковые полевые значения | Разные соседние патчи создают швы, несовпадающие на общих гранях |
| V03 | Масса, центр масс, инерция и объём тела согласованы при раскрытии детей | Масса растёт с уровнем детализации |
| V04 | Добавление пустоты/материала меняет D и восстанавливается из B,D после выгрузки всех кэшей | Удаление кэша стирает отверстие либо материал дублируется |
| V05 | Изменение положения камеры меняет только GPU-представление | Камера меняет коллизии, массу или результат seed |
| V06 | Разрез создаёт автономные FractalRing, сохраняет B/D/seed, массу и мировое положение | Отрыв переопределяет seed, удаляет физическое тело либо создаёт двойную массу |
| V07 | Контакт не сливает объекты; прочный bond может быть удалён без удаления вещества | Обычное падение автоматически сращивает материю |
| V08 | Физическое слипание создаёт новый FractalRing-агрегат, сохраняет дочерние B/D/seed и локальные кадры | Seed агрегата перегенерирует детей или маска пустоты одного тела стирает другое |
| V09 | Жёсткий FractalRing-агрегат суммирует массу/инерцию и учитывает импульс; гравитационные группы независимых тел не меняют принадлежности | Агрегат удваивает массу или гравитационная оптимизация самовольно склеивает объекты |
| V10 | Сериализация B,D и повторный запуск восстанавливают значения поля и топологию при фиксированной версии генератора | Смена генератора незаметно меняет ранее сохранённый мир |

| V11 | После Detach бывшего физического родителя можно удалить: дети продолжают генерацию из канонической родословной | Дочерняя генерация требует живой указатель на удалённый FractalRing |
| V12 | Два бывших процедурных соседа разлетелись на большое расстояние; один использует прежние неизменяемые входы другого | Результат зависит от текущего расстояния, позы или будущих физических изменений соседа |
| V13 | Refine до и после Detach даёт эквивалентную материю при одинаковом каноническом контексте | Момент физического разделения меняет форму или seed |
| V14 | Attach(A,B) создаёт K с локальным кадром, сохраняя мировые позы и seed детей; последующий Detach(A) оставляет B неизменным | При переподчинении происходит сдвиг тела или регенерация процедурного содержимого |
| V15 | Вложенные агрегаты K(L(A,B),C) формируют ациклическую физическую иерархию, сохраняют массу и генерацию частей | Два активных физических родителя у тела, цикл в FractalRing, двойная масса или генерация от seed агрегата |
| V16 | Для шва используем канонические данные соседа, даже если его физический объект уничтожен; независимые запросы дают те же граничные значения | Генератор опирается на mutable pointer соседнего физического тела |
| V17 | Область нового сварного материала может получить новый seed, не меняя seed соединённых деталей | Появление нового интерфейса приводит к полной регенерации ранее существовавших частей |

**Для будущего первого исполняемого эксперимента:** небольшой куб, условно-консервативный адресный seed-генератор, одна 2D-грань, разреженное 3D-изменение, разрез на два тела, физическое соединение как отдельный режим. Измерить не только GREEN/RED, но и память, стоимость случайного запроса и ошибку согласования на границах.
