# Реестр незакрытых исследовательских вопросов

**Статус:** ни один пункт ниже не считается закрытым решением. Прототип E0 должен прояснить возможные ответы, не подменяя вопросы неаргументированными MUST.

| Код | Открытый вопрос | Способ фальсификации / решения |
|---|---|---|
| RQ-01 | Точное семейство полей M: occupancy, density, material composition, SDF? | Сравнить способность представлять пустоты/состав/массу на тестовом кубе |
| RQ-02 | Семантика перекрывающихся изменений D и новое вещество | Проверить порядок-независимый снимок результата, перенос чужих масок пустоты |
| RQ-03 | Реальная граница материи и 2D↔3D сшивка с топологией | Тоннель поперёк двух ячеек; независимые mesh queries без щели |
| RQ-04 | Алгоритм PRNG/seed derivation, число бит, CPU/GPU parity и версии | Fixed test vectors; DFS/BFS/workers; 32-bit wrap старого генератора |
| RQ-05 | Нормы точности и устойчивость mass/inertia для произвольных форм | E0 аналитический куб; позднее численные интеграторы |
| RQ-06 | Физическая модель адгезии, ударного разрушения, связи и Fuse | Сравнить Contact/Attach/Fuse; явный триггер Attach в E0 |
| RQ-07 | Топология разрыва и связность материала (включая точечный контакт) | Разделение не по границам octree, тонкая перемычка |
| RQ-08 | Минимальный компактный контекст Γ при соседозависимой генерации | Удалить бывшего физического соседа/родителя; затем Refine на глубину N |
| RQ-09 | Иммутабельные subtree refs и стабильность идентификаторов при перераспределении | Detach/Attach/Save/Load без двойной массы и потерянных ссылок |
| RQ-10 | Размеры block/brick, spatial index, storage bounds, GC/compaction | Профилировать память и случайные запросы |
| RQ-11 | Формат сохранения, forward/backward generator compatibility | Несовместимая версия должна давать явную ошибку |
| RQ-12 | Стабильность WebGPU WGSL/CPU чисел и визуальных LOD | Отдельный визуальный эксперимент после CPU-oracle |

**Не включать в формальные требования без решения:** конкретный hash/PRNG, обязательный SDF, конкретный meshing алгоритм, hard-coded широкосистемный epsilon, точную механику сцепления, обязательный WebGPU для E0.

Решение требует явного источника и записи Author acceptance, если становится частью обязательного архитектурного baseline.
