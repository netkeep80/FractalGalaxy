# FractalGalaxy — FractalMatter / FractalRing

Исследовательский проект фрактальной материи, в котором **процедурная структура вещества** и **физическая иерархия объектов** независимы.

- **B** — базовый фрактальный объём; **D** — разреженное *результирующее состояние изменений*, а не журнал воздействий; `M=Resolve(B,D)`.
- При фрактализации родительский генератор определяет seed потомков. Физическое отделение **не** создаёт новых seed, а последующее уточнение может использовать исходные неизменяемые параметры процедурных соседей.
- Один независимый физический объект — `FractalRing`. Явный `Attach` двух самостоятельных объектов создаёт **новый родительский FractalRing** со своим пространственным кадром, не заменяя их генераторы; контакт сам по себе не Attach.
- Грани кубических ячеек ≠ физическая поверхность вещества. Quadtree адресует 2D-параметры границы, octree — 3D-объём; оба используют одно авторитетное поле M.
- Масса, инерция и сохранённая физическая иерархия не зависят от камеры/LOD.

## Основные термины

**Начальное значение генератора (seed)** — вход исходного корня; **состояние генератора** — значение родительской/дочерней области, порождаемое при фрактализации; **исходный генеративный контекст (Γ)** — воспроизводимая родословная и неизменяемые параметры исходных соседей. **Присоединение (Attach)** создаёт новый составной FractalRing; **отделение (Detach)** снимает физическую связь уже существующего объекта; **разделение (Split)** перераспределяет исходное M между новыми владельцами; **сращивание (Fuse)** изменяет вещество и не входит в E0.
